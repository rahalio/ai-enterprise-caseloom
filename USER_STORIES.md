# Caseloom — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Engagement / CoE lead

- As a CoE lead, I want to intake a business problem onto the Cognitive Advantage spectrum, so that we do not oversell engagement when automation would pay first.
- As a CoE lead, I want three-leg readiness scored before staffing a build, so that we stop starting science without data or process owners.
- As a CoE lead, I want verified hours-avoided after go-live, so that the next business case is evidence-based.

### Data scientist

- As a data scientist, I want recursive stages (EDA, features, modeling, error analysis) tracked without pretending the work is linear waterfall, so that rework is visible and funded.
- As a data scientist, I want clear packaging acceptance criteria from engineering, so that “model done” means wrappable, not merely notebook-complete.
- As a data scientist, I want ensemble and multi-model composition recorded, so that cognitive claims are inspectable.

### ML engineer

- As an ML engineer, I want a wrap job that produces a deployable package from the scientist’s artifact, so that integration is repeatable across use cases.
- As an ML engineer, I want the target client system and SLA declared early, so that packaging choices match real-time vs. batch reality.

### Business SME / process owner

- As a process owner, I want to define what “good” means in business terms (e.g., complaint routing accuracy, fraud catch rate), so that models optimize the right outcome.
- As an SME, I want a human-review path when confidence is low, so that cognitive automation does not silently misroute high-risk cases.

### Risk / value office

- As a risk reviewer, I want lineage from narratives/source data to package version, so that we can answer regulators after a wrong decision.
- As a value officer, I want factory throughput (use cases in build vs. production) and stage aging, so that the portfolio does not hide zombie prototypes.
- As a sponsor, I want a kill decision when stakeholder buy-in or test-data reliability gates fail, so that budget is not trapped in elusive “AI at scale” theatre.
